# Input to English — promotional film

Current revision: see [40-second v2](README-v2.md). The original30-second production below is retained.

An independent, editable Remotion + Three.js production. The extension source is unchanged.

## Outputs

- `out/input-to-english-1080p.mp4`: 1920 × 1080, 60 fps, 30 seconds, stereo AAC.
- `out/input-to-english-4k.mp4`: 3840 × 2160 intermediate, 60 fps.
- `out/glass-sample-1080p.mp4`: opening three-second material sample.
- `public/audio/master.wav`: mixed 48 kHz stereo audio master.
- `out/verification.json`: encoded delivery validation after `npm run verify`.

## Edit and render

Use Node.js 22+, npm, and FFmpeg on PATH. Dependencies are pinned in package-lock.json.

```powershell
cd F:\chatGPT\Second-Class\promo-video
npm.cmd install
npm.cmd run studio
npm.cmd run typecheck
npm.cmd test
npm.cmd run sample
npm.cmd run render
npm.cmd run verify
```

The `InputToEnglish` composition is 1800 frames. All animation is derived from frame numbers; no live clock, random animation, or network content is used. `src/timing.mjs` defines language slots and beat events. `src/Promo.tsx` owns shots and titles; `Browser.tsx` / `ui-texture.ts` own the glass frame and readable high-resolution UI; `Paths.tsx` / `Logo.tsx` own the blue-to-mint and logo choreography. The final three blue paths become white input strokes before the supplied logo settles.

## Audio and provenance

Nine voice clips were synthesized locally using the existing CosyVoice 3 model and two existing reference recordings, with CUDA. Full texts, reference paths, hashes, crop offsets, and frame positions are in `public/audio/voices-manifest.json`. Raw takes are retained under `public/audio/raw`. No native-speaker fluency review has been performed; speech is a short multilingual texture rather than a full instructional narration.

The original 144 BPM electronic score and synchronized effects are generated by `scripts/generate-score.py`; the final mix is generated by `scripts/mix-audio.py`. Music, effects, and all voice stems remain independently editable. The mix cuts all source-language tails on the frame-600 click, then introduces the English phrase at frame 720. Audio measurement is recorded in `docs/audio-mix.json`.

The supplied project logo is copied into `public/assets/logo.png`. Interfaces are intentionally reconstructed motion graphics. The visible `-> EN`, `Translating…`, Undo, provider labels, and in-place conversion follow the product; no AI answer or automatic submission is depicted.

## Production notes

144 BPM yields exactly 25 frames per beat at 60 fps. Each source language receives 50 frames. Three.js physical transmission, beveled geometry, studio environment reflections, layered depth, and shadows provide the floating glass treatment; high-resolution canvas textures preserve legible content. Remotion renders at scale 2, then FFmpeg downsamples with Lanczos to the delivery resolution.

No original extension files were modified. Generated intermediates and raw assets are intentionally retained; no batch deletion is required.
